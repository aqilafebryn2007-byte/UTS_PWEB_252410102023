# 🎬 FilmKu - Website Pengelolaan Koleksi Film

Website FilmKu merupakan proyek Ujian Tengah Semester (UTS) mata kuliah Pemrograman Web. Website ini dibuat menggunakan Laravel 13 dengan tema pengelolaan koleksi film dan series.

## 📖 Deskripsi Website

FilmKu merupakan website sederhana untuk mencatat film dan series yang sudah maupun belum ditonton. Website ini memiliki fitur login, dashboard, profile, dan pengelolaan koleksi film. Data film disimpan sebagai array di Controller, lalu ditampilkan di halaman pengelolaan.

## ✨ Fitur Website

1. **Login** – Halaman untuk masuk ke website dan mengirim username.
2. **Dashboard** – Halaman utama setelah login, menampilkan sapaan dengan username.
3. **Profile** – Menampilkan halaman profil pengguna.
4. **Pengelolaan Koleksi** – Menampilkan daftar film beserta tahun, genre, dan status tonton.

## 🛠️ Teknologi yang Digunakan

- Laravel 13
- PHP
- Blade Template
- Tailwind CSS
